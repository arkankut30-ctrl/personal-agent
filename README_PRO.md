# الوكيل الشخصي — النسخة الاحترافية

نسخة محسّنة من الوكيل الشخصي المحلي، فيها:

- 🗂️ **جلسات محادثة متعددة** — تقدر تبدأ محادثات جديدة وترجع لأي محادثة قديمة
- ⚙️ **لوحة إعدادات** — تغيير النموذج، تشغيل/إيقاف تأكيد أوامر shell، ثيم فاتح/غامق
- 🧠 **عارض المعلومات المحفوظة** — تشوف وتحذف أي معلومة حفظها الوكيل عنك
- 🔄 **نظام تحديث آمن من GitHub** — يتحقق من وجود نسخة أحدث ويحدّثها بموافقتك فقط

## التثبيت السريع (بدون تحديث تلقائي)

```bash
mkdir -p ~/personal_agent_pro/templates
# انقل الملفات: app.py, memory.py, tools.py, updater.py, VERSION.txt, requirements_pro.txt
# وملف index.html داخل templates/

cd ~/personal_agent_pro
python3 -m venv venv
source venv/bin/activate
pip install -r requirements_pro.txt
python3 app.py
```

افتح المتصفح على: `http://localhost:5000`

## تفعيل التحديث التلقائي من GitHub (اختياري)

هذا الجزء **اختياري بالكامل** — البرنامج يعمل تمام بدونه. لو حبيت تفعّله لاحقًا (مثلًا بعد ما تطوّر الكود بنفسك أو بمساعدتي وتحفظ نسخة على GitHub)، اتبع هذي الخطوات:

### 1. أنشئ ريبو خاص بك على GitHub
سجّل دخول [github.com](https://github.com) وأنشئ ريبو جديد (خاص أو عام، حسب رغبتك).

### 2. ارفع المشروع للريبو
بدل ما تنقل الملفات يدويًا، استنسخه من الريبو من البداية:

```bash
git clone https://github.com/اسم_المستخدم/اسم_الريبو.git ~/personal_agent_pro
cd ~/personal_agent_pro
# ضع كل الملفات هنا، ثم:
git add .
git commit -m "أول نسخة"
git push
```

### 3. عدّل `updater.py`
افتح الملف وعبّي هذا السطر باسم ريبوك:

```python
GITHUB_REPO = "اسم_المستخدم/اسم_الريبو"
```

### 4. من الآن فصاعدًا
- كل ما تطوّر الكود وترفع نسخة جديدة، **رفع نسخة أعلى في `VERSION.txt`** (مثلًا `1.0.1`) وادفعها (`git push`).
- من داخل التطبيق (الإعدادات ⚙️ ← التحديثات)، اضغط "تحقق من التحديثات" — لو وجد نسخة أحدث، يطلع زر "تطبيق التحديث" يسحب الكود الجديد تلقائيًا (`git pull`).

## ⚠️ ملاحظة أمان مهمة

نظام التحديث **لا يسمح للذكاء الاصطناعي بتعديل كوده تلقائيًا بنفسه**. التحديث الوحيد الممكن هو سحب كود كتبته أنت (أو راجعته بنفسك) ورفعته على GitHub. هذا مقصود ومهم — تعديل كود تلقائي بدون مراجعة بشرية خطر حقيقي، خصوصًا مع نموذج محلي صغير قد يخطئ.

## بنية الملفات

| الملف | الوظيفة |
|---|---|
| `app.py` | الخادم الرئيسي (Flask) — الجلسات، الإعدادات، التحديثات |
| `memory.py` | نظام الذاكرة (جلسات متعددة + حقائق + إعدادات) |
| `tools.py` | أدوات الوكيل (كود، shell، بحث إنترنت، حفظ معلومة) |
| `updater.py` | نظام التحديث الآمن من GitHub |
| `VERSION.txt` | رقم النسخة الحالي |
| `templates/index.html` | الواجهة الاحترافية |
